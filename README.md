# Solace Stream Global

Projeto conceitual independente de plataforma global de apoio psicológico voluntário.

## Fonte de verdade
A partir de agora, o desenvolvimento será feito no GitHub. O Lovable não deve ser usado para alterações de código.

## Segurança
- Não declarar afiliação oficial com UNESCO, governos, conselhos profissionais ou universidades sem parceria verificável.
- Não colocar prontuários, gravações, transcrições sensíveis ou outros dados clínicos em tabelas públicas.
- IA é assistiva e não diagnostica nem toma decisões clínicas autônomas.
- O botão de emergência deve encaminhar para serviços locais apropriados e não prometer atendimento de emergência pela plataforma.

## Estado atual
O frontend ainda usa dados fictícios e autenticação demonstrativa. Backend, autenticação real, RLS, auditoria persistente e armazenamento clínico seguro serão implementados em fases posteriores.

## Desenvolvimento
Use Node.js/npm, instale as dependências e execute o script de desenvolvimento definido em package.json.
